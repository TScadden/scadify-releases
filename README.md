# scadify-releases

Release APKs for **Scadify** only — no source code lives here.

Scadify's in-app updater reads the latest release of this repository
(`https://api.github.com/repos/TScadden/scadify-releases/releases/latest`)
anonymously and offers the attached APK as an in-app update. Keeping the
releases in this small dedicated repo keeps the update feed clean: every
release here is a Scadify build, numbered v14, v15, … matching the
versionName inside the APK.

Source code: https://github.com/TScadden/Scadify (GPL-3.0)
